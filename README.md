# WebAssessmentMSC
This is my MSc Computer Science Web development Website It has working Login, Create Account and Reset Password. However, the Cart is not working. To make this work Download XAMPP Local Host. 
How To Install and Run Website
 
Step 1 ) Download the XAMPP Local Host on your machine.
 
Step 3 ) Once Installed Drag the BAYKOST_Website_BradSmith folder into the XAMPP folder titled ‘htdocs’. This can be found in your applications folder on your machine. Usually ‘Applications’ -> ‘XAMPP’ -> ‘htdocs’.
 
Step 4 ) Then Load the XAMPP OS Manager Application.
 
Step 5 ) Click start on the ‘MySQL Database’ and the ‘Apache Web Server’ they should be indicated as working by the Green Light.
 
Step 6 ) Open your browser and type ‘http://localhost/WebAssessmentMSC/index.php’ this should load the home page of the website.
 
Step 7 ) Open your browser and type ‘http://localhost/phpmyadmin/index.php?’ This will take you to a page to manage your databases. Click Create new database and call it ‘testlogin’.
 
Step 8 ) Then Under the same database click import click find file and then find the file titled ‘testlogin.SQL’ it will be in the sub folder ‘data’ of the WebAssessmentMSC Folder. Finally Click Import and it will import all the data and relationships.

If this doesnt work instead loacate inside the data folder the RTF(Rich Text File) called SQLCOMMANDS and copy the text and paste into the sql command line
